## Run locally

Open `index.html` directly in your browser.

For a local server, from this folder run:

```bash
python -m http.server 5500
```

Then open:

`http://localhost:5500`

## Publish and get a shareable portfolio link

### GitHub Pages

1. Create a new GitHub repository, for example:
   `ummehabiba-portfolio`
2. Upload `index.html`, `styles.css`, and the `assets` folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/root`.
6. Save.
7. GitHub will provide your public website URL.

### Netlify

Drag this entire folder into Netlify's deploy area. Netlify will generate a public URL.
